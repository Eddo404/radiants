# Radiant Alert (client-side Fabric mod, MC 1.21.1)

Build:   gradle build        (needs JDK 21 and Gradle 8.10+; or open the folder in IntelliJ and run the `build` task)
Output:  build/libs/radiant-alert-1.0.0.jar
Install: drop the jar into your Cobblemon Delta instance's `mods` folder.

If Delta's Cobblemon version differs, edit `cobblemon_version` in gradle.properties.
In-game: /radiantalert debug  -> prints aspects of the nearest Pokémon (use on a radiant to confirm detection).
